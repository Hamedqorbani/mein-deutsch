# Mein Deutsch — آلمانی من

وب‌اپ واکنش‌گرا برای یادگیری زبان آلمانی با رابط فارسی، قابل نصب به‌صورت PWA و دارای پشتیبانی آفلاین.

## وضعیت فعلی
- سطح **A1** فعال است؛ سطح‌های A2، B1، B2، C1 و C2 فعلاً به‌صورت گزینه‌های غیرفعال نمایش داده می‌شوند.
- فلش‌کارت، دیکشنری و جستجوی دوطرفه فارسی/آلمانی، تلفظ، مثال و صرف فعل دارد.
- تمرین‌های کتابی شامل آرتیکل‌های رنگی (der آبی، die قرمز، das سبز)، دسته‌بندی خوراکی‌ها، اعداد ۱ تا ۱۰۰، کامل‌کردن جمله، تشخیص کلمه متفاوت و مرتب‌سازی کلمات است.
- آزمون ترکیبی A1 با ۱۰ سؤال، زمان ۹۰ ثانیه، امتیاز از ۱۰۰ و مرور پاسخ‌های اشتباه دارد.
- تمرین شنیداری اعداد، همه اعداد ۱ تا ۱۰۰ را پوشش می‌دهد و از صدای آلمانی مرورگر استفاده می‌کند.
- فلش‌کارت‌های شخصی، پیشرفت و تنظیمات روی همان دستگاه ذخیره می‌شوند؛ امکان تهیه و بازیابی نسخه پشتیبان وجود دارد.
- بخش معلم هوشمند فعلاً پاسخ‌های آموزشی محلی دارد و هنوز به مدل هوش مصنوعی آنلاین متصل نیست.
- برای استفاده آفلاین، برنامه باید ابتدا یک‌بار با اینترنت بارگذاری شود. صدا و قابلیت‌های وابسته به مرورگر ممکن است در حالت آفلاین محدود باشند.

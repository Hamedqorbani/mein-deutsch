# Mein Deutsch — آلمانی من

وب‌اپ واکنش‌گرا برای یادگیری زبان آلمانی، با رابط فارسی و پشتیبانی از نصب به‌صورت PWA.

## وضعیت نسخه
- سطح **A1** فعال است و مجموعه واژگان اولیه، فلش‌کارت، جستجو، دیکشنری، صرف فعل و تمرین آموزشی دارد.
- گزینه‌های A2، B1، B2، C1 و C2 در رابط دیده می‌شوند، اما فعلاً خالی هستند و بعداً تکمیل می‌شوند.
- تنظیمات و پیشرفت آموزشی روی همان دستگاه ذخیره می‌شود.
- بخش معلم هوشمند فعلاً پاسخ‌های تمرینی محلی دارد و هنوز به مدل هوش مصنوعی آنلاین متصل نیست.
- برای استفاده آفلاین، سایت باید ابتدا یک‌بار با اینترنت بارگذاری شود؛ قابلیت‌های وابسته به سرویس آنلاین در حالت آفلاین کار نمی‌کنند.
